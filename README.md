# La Mela d’oro · Zeitz

Die fertige statische Website liegt in [`website/dist/`](website/dist/). `index.html` im Repository-Stamm leitet dorthin weiter, damit GitHub Pages mit `main` und `/ (root)` als Veröffentlichungsquelle funktioniert. `.nojekyll` sorgt dafür, dass die Dateien unverändert ausgeliefert werden.

Die Website-Dokumentation und Hinweise zum Bearbeiten der Speisekarte stehen in [`website/README.md`](website/README.md).
